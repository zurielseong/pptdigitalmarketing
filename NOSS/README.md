## Key Difference: Level 3 vs Level 4

| Dimension | Level 3 — Operation | Level 4 — Planning & Implementation |
|-----------|---------------------|--------------------------------------|
| NOSS Code | M731-001-3:2021 | M731-001-4:2021 |
| Core verb | **Execute** | **Plan and Implement** |
| Focus | Carrying out tasks operationally | Strategic planning + coordination + optimisation |
| Evidence depth | "I did X" | "I planned X, delegated Y, evaluated Z" |
| Budget role | Uses allocated budget | **Allocates and manages** budget |
| Team role | Team member | **Team leader / coordinator** |
| Reporting | Submits reports | **Analyses reports, makes decisions** |
| CUs covered | 6 CUs | **7 CUs** (adds CU7 Reputation Management) |

## What "Bukti Kukuh" (Strong Evidence) Looks Like at Level 4

JPK assessors will look for these markers in every document:

| Marker | Level 3 (not enough) | Level 4 (required) |
|--------|---------------------|--------------------|
| Budget | "The budget was RM X" | Budget allocation TABLE with line items, monthly breakdown, and reallocation decisions |
| Team | "I worked with staff" | Task DELEGATION TABLE with names, frequencies, escalation protocols |
| Decisions | "I posted the content" | "I reviewed CTR data and reallocated budget from X to Y because Z" |
| Reporting | Submits a report | Analyses the report and makes recommendations |
| Planning | Follows a plan | Creates the plan, gets it approved, updates it based on results |
| Risk | N/A | Risk register with likelihood, impact, mitigation |
| Optimisation | Makes changes | A/B test → data → decision → outcome documented |
