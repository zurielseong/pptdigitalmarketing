# SEO Channel Assessment Report
## Competency Unit 2: Search Engine Optimisation Plan
**M731-001-4:2021 — Digital Marketing Planning & Implementation (Level 4)**

---

## 1. Strategic Purpose

This SEO Channel Assessment was commissioned to evaluate the current organic search performance of TVET Lipis (tvetlipis.my), identify critical content and technical gaps, and provide a data-informed baseline for the development of a structured SEO Improvement Proposal. The assessment supports the institution's strategic goal of increasing qualified student enrolment enquiries through organic search channels without reliance on paid advertising.

This document serves as the formal foundation for all subsequent SEO planning decisions and resource allocation.

## 3. Assessment Scope

This assessment covers the following dimensions:
1. Technical SEO capabilities and limitations of the Canva platform
2. On-page SEO audit of existing page structure and content
3. Keyword landscape analysis for TVET/SKM vocational programmes in Malaysia
4. Competitor benchmarking (similar TVET institutions)
5. Off-page authority signals
6. Google Search Console and Analytics integration status

---

## 4. Technical SEO Audit

### 4.1 Platform Capabilities (Canva Website)

| SEO Element | Canva Capability | Status | Risk Level |
|------------|-----------------|--------|------------|
| Custom domain (tvetlipis.my) | Supported | ✅ Implemented | Low |
| SSL/HTTPS | Automatic | ✅ Active | Low |
| Meta title (per page) | Supported | ⚠️ Partially configured | Medium |
| Meta description | Supported | ⚠️ Missing on 3+ pages | Medium |
| Open Graph tags | Limited | ⚠️ Default only | Medium |
| Sitemap.xml | Auto-generated | ✅ Available | Low |
| Robots.txt | Auto-generated | ✅ Available | Low |
| Canonical tags | Not configurable | ❌ No control | High |
| Structured data (Schema.org) | Not supported | ❌ Absent | High |
| Blog/CMS | Not supported | ❌ No dynamic content | High |
| Page speed (Core Web Vitals) | Image-heavy by default | ⚠️ Needs optimisation | High |
| Mobile responsiveness | Auto-responsive | ✅ Compliant | Low |

**Key Finding:** The Canva platform provides a visually polished website but has significant technical SEO limitations, particularly the absence of Schema.org structured data and a CMS for fresh content publication. These constraints must be addressed in the improvement strategy.
